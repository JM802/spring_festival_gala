## 📖 项目简介

这是一个以**春晚魔术**为灵感创作的 Web 应用计算器。用户输入三个数字，无论第三个数字输入什么，最终结果都会神奇地等于当前时间（或春晚固定时间）对应的数字！

项目采用 **Flask + HTML/CSS/JavaScript** 技术栈，拥有精美的春节主题界面、流畅的交互动画和绚丽的烟花特效。

## 🚀 快速开始

### 1️⃣ 环境要求

- Python 3.8 或更高版本
- 现代浏览器（Chrome、Firefox、Edge、Safari）

### 2️⃣ 安装步骤

```bash
# 1. 克隆或下载项目
cd SPRING_FESTIVAL_GALA

# 2. 创建虚拟环境（推荐）
python -m venv venv

# 3. 激活虚拟环境
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate

# 4. 安装依赖
pip install -r requirements.txt

# 5. 启动服务
python backend/app.py

# 6. 打开浏览器访问
http://localhost:5000
```

### 3️⃣ 停止服务

```bash
# 在终端按 Ctrl + C 停止服务

# 退出虚拟环境
# Windows:
venv\Scripts\deactivate
# Mac/Linux:
deactivate
```

## ⚙️ 配置说明

### 修改春晚时间

编辑 `backend/app.py`，找到以下代码：

```python
# 春晚固定时间 2 月 16 日 22:27
m, d, h, mm = 2, 16, 22, 27
```

修改为任意时间即可。

### 修改主题颜色

编辑 `static/css/style.css`，修改 CSS 变量：

```css
:root {
    --primary-red: #c41e3a;      /* 主红色 */
    --primary-gold: #ffd700;     /* 主金色 */
    --bg-dark: #0a0a0a;          /* 背景色 */
}
```

### 修改服务端口

编辑 `backend/app.py`，修改端口号：

```python
app.run(debug=True, host='0.0.0.0', port=5000)  # 改为其他端口
```
